# Loan Tracking System

A web application built using Django to manage borrowers, loans, and weekly collections.

## Features

- Add and manage borrowers
- Create loan records
- Track weekly collections
- Calculate remaining loan balance
- Dashboard to monitor loan status

## Tech Stack

- Python
- Django
- HTML
- CSS
- SQLite / MySQL

## Project Structure

loan-tracking-system
│
├── manage.py
├── borrowers
├── loans
├── templates
├── static
└── db.sqlite3

## Installation

1. Clone the repository

git clone https://github.com/tejadusanapudi781-creator/loan-tracking-system.git

2. Navigate to the project folder

cd loan-tracking-system

3. Install dependencies

pip install -r requirements.txt

4. Run the server

python manage.py runserver

5. Open in browser

http://127.0.0.1:8000/
